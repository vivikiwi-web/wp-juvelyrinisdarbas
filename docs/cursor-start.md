# Работа с проектом в Cursor

Открой папку:

```text
/Users/vitalijvirsulo/Local Sites/juvelyrinisdarbas/app/public/wp-content/themes/savoy-child
```

Подготовлены общий [AGENTS.md](../AGENTS.md) и одно постоянное проектное правило `.cursor/rules/project.mdc`. Оно направляет агента к основному файлу и нужным процессам; не дублирует все требования.

Формат `.mdc` с `alwaysApply: true` соответствует [документации Cursor](https://cursor.com/docs/rules), проверенной 2026-11-24; установленная версия на момент подготовки — 3.30.14. Автоматическое применение в интерфейсе ещё не проверялось. В настройках правил убедись, что правило обнаружено для этой папки. Другие агенты не обязаны читать `.cursor/rules`; общий контекст хранится в `AGENTS.md`.

## После первого запуска

Давай агенту конкретную задачу с проверяемым результатом. Например: «Подготовь Git для этой дочерней темы: перепроверь локальное и удалённое состояние, безопасно свяжи их и создай отдельную ветку; код сайта и БД не меняй». Это пример будущего поручения, а не разрешение выполнить его при чтении файла.

Для реализации панели сначала согласуй нужные решения из `docs/decisions.md`. Для каждой задачи достаточно сослаться на `AGENTS.md` и указать результат; весь исходный контекст заново вставлять не нужно. Не поручай двум редакторам одновременно менять одни и те же файлы или БД.
