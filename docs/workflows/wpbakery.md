# WPBakery и страницы

Основные требования: [AGENTS.md](../../AGENTS.md). Для запросов к БД используй [wp-cli-local.md](wp-cli-local.md).

## Сначала исследовать

- Через WP-CLI прочитай ID, статус, `post_content` и относящиеся к задаче метаполя нужной страницы, не выгружая лишние контактные данные.
- Изучи существующие шорткоды и регистрацию элементов в `plugins/nm-custom-code/includes/visual-composer/` и `includes/shortcodes/` (только чтение).
- До записи сохрани точечные исходные значения вне Git; отдельно учитывай настройки Savoy и метаданные WPBakery.
- Не заменяй `post_content` статическим HTML или блоками другого редактора.

## Исходная главная

На дату [аудита](../audit-2026-11-24.md): Shop 10 назначена магазином и главной, Home 757 подключена Savoy над каталогом через `shop_content_home=1`, `shop_page_id=757`.

Home содержит `vc_row` / `vc_column` / `nm_banner_slider` / три `nm_banner`. Сетка товаров выводится Savoy отдельно; не дублируй её новым shortcode без необходимости.

`nm_banner` поддерживает заголовок, подзаголовок, ссылки/кнопки, обычное и альтернативное изображение. Сохраняй редактируемые текст и CTA отдельно от фотографии. Изображения без встроенных надписей создаются только по отдельной задаче.

## Изменение

- Меняй только назначенную страницу и относящиеся к ней настройки. Сохраняй вложенность и корректное экранирование атрибутов шорткодов.
- Записывай разрешённые изменения API WordPress/WP-CLI, не слепым SQL по сериализованным данным.
- Проверь зарегистрированные элементы, существование ID изображений и CF7, совместимость дополнительного CSS и метаполей с редактором.
- Не удаляй демостраницы, меню и товары массово без поручения на очистку и проверки зависимостей.
- Contact - Form 545 на дату аудита ссылалась на отсутствующую форму 5: прежде чем исправлять, выбери согласованную форму, не подставляй случайный ID.

## Приёмка

Страница открывается и сохраняется в WPBakery; hero и кнопки редактируются; frontend корректен на desktop/mobile. Сохранилась компоновка Savoy. В отчёте перечислены изменённые ID и метаполя/настройки БД отдельно от кода.
