# Импорт изделий и SEO

Основные ограничения: [AGENTS.md](../../AGENTS.md). Полный импорт не разрешается самим существованием этого документа.

## Источники и предварительная таблица

1. Получи доступную копию старых файлов/БД или другой согласованный источник. Не изменяй действующий сайт. Не складывай копию в Git или публичную папку темы.
2. Исследуй типы записей, галереи, подписи, имена файлов, номера изделий и реальные связи. Отдельно собери URL, title, description и доступные canonical/redirect.
3. Подготовь предварительную таблицу и отчёт неоднозначностей до создания товаров. Не используй название как единственный ключ.

Предлагаемые столбцы таблицы: `source`, `source_id`, `source_url`, `legacy_number`, `sku`, `category`, `title_lt`, `description_lt`, `image_source_ids`, `confirmed_attributes`, `availability_source`, `target_slug`, `review_status`, `notes`. Финальную схему уточни по реальным данным.

Неизвестные характеристики, цена и наличие остаются пустыми/неподтверждёнными, а не получают значения по умолчанию «в наличии» или 0. Фотография не подтверждает технические характеристики металла и камней.

## Реализация после поручения

- Собственный импортёр размещается в дочерней теме, например как WP-CLI-команда. Не устанавливай плагин импорта без необходимости и согласованной задачи.
- Постоянный ключ — пара источника и исходного ID. Если у источника нет ID, сначала согласуй воспроизводимый ключ, не зависящий только от заголовка.
- Режим dry-run не пишет товары, вложения и настройки. Показывай план create/update/skip/conflict/error.
- Используй API WC/WordPress. Отдельно обеспечь повторное использование медиа по постоянному ключу источника, а не только по имени файла.
- Не перезаписывай ручные изменения без заранее определённой политики владельца полей. Поддержи продолжение после сбоя и отчёт без персональных данных.
- Сопоставляй только подтверждённые категории. Сомнительные данные отправляй на проверку.
- Сохраняй подходящие старые адреса. Для изменённых — конкретные 301 на релевантные страницы, без массового перенаправления на главную.

## Приёмка

Небольшая согласованная тестовая партия проверена владельцем. Повторный запуск не создаёт дубли товаров и медиа; исправление исходных данных корректно обновляет назначенные поля. Есть отчёт несовпадений и пропущенных изображений, проверка SKU/источника, URL и восстановления. Полный импорт выполняется только после отдельного согласования.
