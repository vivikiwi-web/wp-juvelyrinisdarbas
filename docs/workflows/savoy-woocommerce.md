# Savoy / WooCommerce

Сначала прочитай [AGENTS.md](../../AGENTS.md). Архитектура и модель данных находятся в [architecture.md](../architecture.md), статус решений — в [decisions.md](../decisions.md).

## Перед изменением

1. Проверь Git и границы текущей задачи.
2. Прочитай соответствующие хуки/шаблоны установленной Savoy и текущей WooCommerce. Не используй предполагаемые хуки без проверки исходников.
3. Проверь применимые настройки и существующие собственные обработчики, чтобы не добавить дубли.
4. Раздели изменение кода и изменение БД; для последнего подготовь восстановление и точный объём.

## Опорные места исходников

Пути относительно `wp-content`:

- `themes/savoy/includes/options/options-config.php`: Catalog Mode, сетка, область контента над магазином.
- `themes/savoy/includes/options/default-options.php`: значения по умолчанию; не путать с настройками в БД.
- `themes/savoy/assets/css/shop.css`: раздел Catalog Mode, включая скрытие наличия.
- `themes/savoy/functions.php`: `nm-catalog-mode`, состояние штатной корзины и другие хуки.
- `themes/savoy/includes/woocommerce/` и `themes/savoy/woocommerce/`: интеграция и шаблоны.
- `themes/savoy/template-parts/woocommerce/cart-panel.php` и `themes/savoy/woocommerce/cart/mini-cart.php`: оболочка, список и нижние действия панели; доступны точечные переопределения в child theme.
- `plugins/woocommerce/includes/abstracts/abstract-wc-product.php` и `class-wc-product-variation.php`: покупаемость.
- `plugins/woocommerce/includes/class-wc-form-handler.php`, `class-wc-ajax.php` и реализация Store API текущей версии: пути покупки.

Все эти файлы только для чтения. Новую реализацию размещай в дочерней теме.

## Практика

- Администраторские поля добавляй штатными хуками WooCommerce; проверяй полномочия, nonce, допустимые значения и очистку данных.
- Для товаров/импорта предпочитай CRUD WooCommerce, а не прямую запись служебных таблиц и индексов.
- Не используй цену 0 как замену отсутствующей цене и не включай глобально покупаемость ради запросов.
- Владелец выбрал дизайн штатной панели Savoy и сохранение запроса в WC-заказе. Не включай Catalog Mode автоматически: он отключает эту панель и скрывает все цены. Использование WC cart как списка ещё не утверждено; отделяй разрешённое добавление в запрос от покупки/оплаты.
- Заказы-запросы сохраняй через WC CRUD, с защитой от повторов и без оплаты, резервирования/списания. Жизненный цикл статусов и влияние на письма/отчёты проверяются отдельно; не копируй `processing` из Bioresus.
- Не удаляй функции WooCommerce произвольными вызовами и не отключай целиком его API ради каталога.
- CTA панели и текст наличия должны переживать AJAX-перерисовку сетки Savoy и quick view, если этот сценарий включён.
- При переопределении шаблона фиксируй причину, версию исходника и проверку после обновления Savoy/WC.

## Приёмка

Каталог/карточки/админка работают; четыре колонки desktop сохранены; мобильная сетка согласована. Владелец может редактировать данные. Нельзя обойти запрет покупки прямым запросом, но разрешённые запросы на изделие и административные операции работают. Наличие не исчезает вместе со штатным CSS Catalog Mode.

## Порядок каталога и надписи наличия — 2026-11-24

По поручению владельца верхние категории идут так: `Vestuviniai žiedai`, `Sužadėtuvių žiedai`, `Žiedai`, `Juvelyriniai dirbiniai`; `Visi` остаётся первым. Фильтры Savoy `nm_shop_category_menu_args` / `nm_shop_sub_category_menu_args` помечают только нужные запросы терминов. Порядок применяется через `terms_clauses`, не меняя глобальный порядок терминов/БД.

`inc/catalog-order.php` использует тот же приоритет для стандартной сетки WooCommerce. Внутри группы сохраняется штатный menu_order/название, ID служит дополнительным стабильным критерием. Если у товара несколько категорий, применяется наивысший приоритет; коррелированный MIN не дублирует строки товара и сохраняет пагинацию. Сортировка по цене, дате и другим явно выбранным критериям не переопределяется; поиск и административные запросы не группируются.

В `inc/catalog.php` бейдж для `outofstock` переименован в `Užsakoma` в сетке и карточке; `Turime` / `Turime vietoje` сохранены. Stock status, цены и разрешённые параметры не меняются.
