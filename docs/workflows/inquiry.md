# Панель запроса и CF7

Сначала прочитай [AGENTS.md](../../AGENTS.md), [architecture.md](../architecture.md) и [decisions.md](../decisions.md). Этот документ описывает будущую реализацию, а не существующую функциональность.

## Подготовка

Уточни количество изделий, восстановление, матрицу обязательности, контакты, референсы, политику цен и статус заказа в объёме текущей задачи. Хранение запроса в заказе WC и использование дизайна панели Savoy уже подтверждены. Проверь хуки установленной CF7, в частности в `includes/submission.php`, и ограничь обработчики нужной формой.

В Bioresus полезны идея sheet, overlay, Escape, body lock, состояния загрузки и серверный рендер данных. Код зависит от собственной системы компонентов, SCSS и JS helpers. Не копируй весь проект, количество 10 по умолчанию, глобальную покупаемость или создание `processing`-заказа.

## Предварительная матрица параметров

| Тип | Возможные пожелания |
| --- | --- |
| Обручальные кольца | Размер каждого кольца, материал, цвет золота, гравировка, комментарий |
| Помолвочные / другие кольца | Размер, материал, цвет золота, пожелания к камню при разрешении, комментарий |
| Цепочки / браслеты, если категории подтверждены | Длина, материал, цвет золота при применимости, комментарий |
| Серьги / подвески | Материал, цвет золота при применимости, пожелания к камням при разрешении, комментарий |

Это не утверждённые обязательные поля и не автоматическая схема WC variations. Для готового изделия разрешённые изменения определяются отдельно.

## Сервер

- При чтении и отправке проверь product ID, публикацию, видимость и допустимый конкретный вариант, если он предусмотрен.
- На отправке заново проверь наличие/разрешённый сценарий и применимость каждого параметра. Сохранённое состояние браузера может устареть.
- Введи allowlist полей, типов, значений и ограничений длины/диапазона; неприменимые значения отклоняй или нормализуй по явно определённому правилу.
- Материал и цвет проверяются совместно: нельзя принять цвет золота для серебра. Пользователь не задаёт складское наличие.
- Формируй название, SKU, URL и сведения об изделии из БД для письма и архива. Скрытые поля — только транспорт, не источник истины.
- Интегрируй проверку до отправки CF7, не отдельным действием после браузерного события успеха.
- Создавай ровно один WC-заказ-запрос через CRUD с учётом HPOS, только после серверной проверки. Сохраняй сценарий и параметры в метаданных позиций, отмечай тип запроса. Не вызывай оплату, резервирование и списание; не используй `processing`/`on-hold` как статус заявки по образцу Bioresus.
- Согласуй статус (рекомендация — `Užklausa`) и проверь административные права, срок хранения, защиту от повторов, запрет оплаты через order-pay и частичные ошибки сохранения/письма. Не отправляй дополнительные стандартные письма WC без необходимости.
- Не храни контактные данные в URL и browser storage. Неизвестная цена не считается нулевой стоимостью изделия; известная цена берётся с сервера, её смысл ещё нужно определить. Не выводи полный итог для списка с неполными ценами.
- Если файлы разрешены, проверь размер, количество, расширение/MIME, место хранения и доступ. Не помещай загрузки в репозиторий.

## Интерфейс

- Повторно используй внешний вид и механику панели Savoy; переопределяй только необходимые шаблоны в child theme. Переведи заголовок/действия/ошибки на литовский, размести CF7 внизу вместо View cart/Checkout. Не создавай ещё одну панель рядом со штатной.
- Оболочка: `template-parts/woocommerce/cart-panel.php`; список: `woocommerce/cart/mini-cart.php`. Хуки предпочтительнее копирования. Форму рекомендуется поместить в оболочку вне `div.widget_shopping_cart_content`, который Savoy заменяет AJAX-фрагментом. Проверь сохранение ввода после изменения/удаления позиций и фильтрации каталога.
- Не включай Catalog Mode вслепую: он отключает панель и скрывает все цены. Если используется WC cart/session, проверь отдельно запросы на изделия без цены и изготовление без готового остатка; не решай это глобальным `woocommerce_is_purchasable=true`.
- Управляй фокусом при открытии, удерживай его в модальном диалоге, возвращай на кнопку при закрытии. Закрытая панель недоступна для tab-навигации.
- Предусмотри Escape, overlay/кнопку закрытия, блокировку прокрутки, мобильную клавиатуру, прокрутку содержимого и уменьшение анимации по пользовательским настройкам.
- Отобрази загрузку, сетевую ошибку, ошибку валидации и отправки по-литовски; при ошибке сохрани ввод и разреши исправление/повтор.
- После успеха сбрасывай только отправленный запрос и не стирай более новый выбор из-за запоздавшего ответа.

## Приёмка

Проверь готовое изделие, изготовление, оба сценария и отсутствие доступного сценария; изделия с ценой и без цены; неверный/удалённый ID; неподходящую вариацию; подмену названия, SKU, наличия и параметров; изменение доступности до отправки; сеть/CF7 error; повторный клик; открытие после фильтрации Savoy; desktop/mobile/клавиатуру. Подтверди создание одного неоплаченного заказа-запроса, отсутствие дублей при ошибке письма, резервирования и изменений остатков; запрет прямой оплаты и корректность писем/отчётов WC. Проверь сохранение введённых контактов при обновлении списка. Почту проверяй в локальном перехватчике, не утверждай, что `mailsent` гарантирует доставку адресату.
