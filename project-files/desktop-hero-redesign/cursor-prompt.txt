Сдержанный ювелирный бренд: выразительная типографика, много воздуха, спокойные золотистые детали. Фотография остаётся во всю ширину hero, текст расположен слева на её существующей тёмной области. Не добавляй рамку вокруг текстового блока, стеклянные панели, новые фотографии, каталог, второй CTA, счётчик слайдов или дополнительный контент.

Desktop >=1024px

2. Текстовый блок — примерно в 9% от левого края hero, вертикально по центру, ширина около 36–39% (до 560–600px). Подбери ширину по реальной фотографии, чтобы длинный заголовок не заходил на кольца. Не задавай глобальные изменения контейнеров Savoy.
3. Над заголовком покажи существующий jd_eyebrow: 12–13px, обычное начертание, uppercase через CSS, letter-spacing около .15em, цвет #d6ba84. Слева короткая горизонтальная линия 28x1px через ::before, gap около 14px. Отступ до заголовка 20–22px. Если поля нет/оно пустое, не создавай элемент и не оставляй зарезервированное место.

На широком desktop стремись к двум естественным строкам «Jūsų istorijai / sukurti žiedai». Для естественного переноса можно ограничить сам заголовок max-width около 9.3em, проверив все ширины. Без <br> в PHP/контенте и без жёстко заданной высоты заголовка; допустим text-wrap: balance, с проверкой реальной ширины. Размеры относить к фактическому hero и скорректировать на 1024/1280, чтобы сохранить пространство под навигацию.

- Новые стили — отдельный assets/scss/components/_hero-desktop.scss, подключённый через @use в main.scss. Все правила ограничь .jd-home-hero и @media (min-width:769px), с дополнительными диапазонами по необходимости.
- Проверь реальные селекторы .nm-banner-content, .nm-banner-content-inner.h_left.v_center, .nm-banner-text.large (сейчас inline max-width:45%;padding:0 0%), .nm-banner-text-inner, .nm-banner-title, .nm-banner-subtitle.nm-alt-font, .nm-banner-link.type-btn. Для inline max-width сначала проверь, достаточно ли задать меньшую width при существующем максимуме; если понадобится !important, только для конкретного свойства локального компонента с пояснением.
