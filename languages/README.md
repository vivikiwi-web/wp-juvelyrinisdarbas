# Литовский перевод Savoy

Основные правила проекта: [AGENTS.md](../AGENTS.md).

- `lt_LT.po` — редактируемый литовский словарь интерфейса темы (`nm-framework`).
- `lt_LT.mo` — скомпилированный словарь, который загружает WordPress.
- `en_US.po` / `en_US.mo` — исходные файлы дочерней темы; сохранены без изменений.
- `nm-wishlist-lt_LT.po` / `.mo` — перевод отдельного домена избранного, включая пустой список, кнопку возврата и подсказки иконок.
- `woocommerce-lt_LT.po` / `.mo` — дополнение к официальному WooCommerce: точный ключ `Load more`, используемый пагинацией Savoy (регистр отличается от `Load More` в словаре темы).

На 2026-11-24 переведена 271 запись, включая контекстные строки и три формы множественного числа. Собраны строки из текущего PHP-кода Savoy 3.2.4 для домена `nm-framework`, комплектного `savoy.pot` и исходного `en_US.po`: комплектный POT не охватывает все строки текущей версии.

Savoy уже вызывает `load_theme_textdomain('nm-framework', get_stylesheet_directory() . '/languages')`. Поэтому для активной дочерней темы и языка сайта `lt_LT` дополнительный PHP-загрузчик не нужен. Родительская тема не изменяется.

Для двух дополнительных доменов используется `inc/translations.php`, подключённый из `functions.php`. На `init` после регистрации словарей плагинов сначала разрешается их штатный перевод, затем загружается дополнительный MO. Установленные переводы не заменяются одним коротким словарём; изменения плагинов не требуются. Дополнения применяются только для локали `lt_LT`.

## Обновление перевода

Редактируй `lt_LT.po` в Poedit или другом gettext-редакторе. Сохраняй оригинальные `msgid`, контексты, параметры форматирования (`%s`, `%1$s`), HTML-сущности и значимые пробелы. Имена разработчика, темы и URL не переводятся. Литовское правило множественного числа согласовано с установленным словарём WordPress.

Из корня дочерней темы проверь и пересобери MO:

```sh
msgfmt --check --check-format --statistics languages/lt_LT.po -o languages/lt_LT.mo
msgfmt --check --check-format --statistics languages/nm-wishlist-lt_LT.po -o languages/nm-wishlist-lt_LT.mo
msgfmt --check --check-format --statistics languages/woocommerce-lt_LT.po -o languages/woocommerce-lt_LT.mo
```

После обновления Savoy повторно извлеки строки домена `nm-framework` из установленного кода с помощью `wp i18n make-pot` во временный POT, сравни с текущим PO и переведи новые строки. Не изменяй коммерческую родительскую тему и не заменяй перевод только её устаревшим комплектным POT.

## Границы перевода

Основной словарь переводит интерфейс Savoy, а не содержимое БД: названия меню, тексты баннеров/страниц, товары, категории, пользовательские поля настроек и шаблоны форм CF7 меняются отдельной задачей. Строки WordPress, WooCommerce и CF7 используют собственные установленные литовские словари; для WooCommerce и Wishlist добавлены перечисленные выше дополнения. Административные настройки Savoy (`nm-framework-admin` / Redux) и остальные домены плагинов NordicMade не считаются переведёнными этими файлами.

Термины корзины и оплаты переведены с исходным смыслом. Переименование корзины в панель запроса и добавление формы/заказов относятся к будущей реализации, а не к локализации.
